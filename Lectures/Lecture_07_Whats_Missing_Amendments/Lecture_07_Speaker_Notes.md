# Lecture 7 Speaker Notes — What's Missing / Amendments

**Course:** USGOVT101

## Empowerment

Name the original bargain’s failure by its own standards, map the main formal renegotiations, state why formal amendment is hard and valuable, and hold Spooner’s consent question open.

## Narrative spine

Unfinished contract → breach (slavery as antithesis) → Douglass → amendments as renegotiation → ink needs backup → ERA unfinished + 14th angle → Spooner open → "what else?"

## Douglass

1852 speech: condemn the breach and invite the country to live up to its own ideals. Full text/video already on the TikTok channel.

## Amendments

Civil War trio as the radical rewrite. Voting/participation cluster (17, 19, 24, 26) as expanding who gets a formal say.

ERA: attempted, not ratified. One view: possibly unnecessary if the 14th already covers persons. Counter: 14th is not explicit on sex.

## Spooner

Leave open. Because almost no one gives explicit personal consent, respecting basic rights is both an ethical duty and a practical necessity.
